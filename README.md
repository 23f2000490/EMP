# Examination Management Portal (EMP)

A Flask-based web application for managing examinations with three roles:
Admin, Examiner and Student. Admins manage courses, examinations, rubrics
and examiners. Examiners create examination slots and evaluate students.
Students book slots, view schedules and see published results.

## Tech Stack
- Flask (backend)
- Jinja2, HTML, CSS, Bootstrap (frontend)
- SQLite (database, created programmatically)
